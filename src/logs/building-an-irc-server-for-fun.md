# Joining your own irc channel from two devices just to make it feel alive

I built a small IRC server to learn how the protocol works.

After getting it working, I opened two terminals, `hvalec` and `hvalec2`, joined the #general channel, and sent a message from one. The other client received it.

No one else was there.
